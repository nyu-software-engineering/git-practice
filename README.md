## Interesting Software Engineering Article

[Technical Debt — Martin Fowler](https://martinfowler.com/bliki/TechnicalDebt.html)

### Why I Found It Interesting

This article explains the idea of **technical debt** and how decisions made during software development can affect a project later. Comparison between technical debt and financial debt was interesting: taking a shortcut may make development easier in the short term, but it can create additional work when the software needs to be changed or extended.

This topic is relevant to software engineering because writing code is not only about making something work once. Developers also need to think about maintainability, readability, and how easily other developers can modify the system in the future. it made me consider more carefully about the trade-offs between developing features quickly and keeping a codebase easy to maintain.
